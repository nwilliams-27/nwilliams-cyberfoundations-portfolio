**What's the difference between a file and a folder, and how do they form a tree together?**

Files are specific items stored on my computer and a folder is what holds the files. For example, when I complete my weekly checks, I save the document as Weekx (file) in a folder that I titled CyberFoundations. Files are one unit and folder contain multiple units. **How does a Windows-style file path differ from a Linux-style file path?**

```
The Windows style file path differs from a Linux style file path based on the following:

Windows uses backslashes C:\users\nwilliams\documents

Linux uses forward slashes /home/nwilliams/Documents

In Windows each drive has it's own root (C:\\ D:\\)

In Linux there's one root for everything (/) no matter what drive the file is stored on.

Windows paths are not case sensitive. Williams.txt, WILLIAMS.TXT and williams.txt are the same files and cannot coexist in the same folder.

Linux paths are case sensitive. Williams.txt, WILLIAMS.TXT and williams.txt are not the same files and can coexist in the same folder.
```
